# Hà Nội · Diorama 3D

Interactive Three.js miniature of Hà Nội — same genre as [Đà Nẵng · Diorama 3D](https://danang-diorama.netlify.app/), with Hoàn Kiếm Lake, the Old Quarter, colonial rooftops, and a lantern evening.

## Run locally

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5174/

## Controls

- **Overview / Lake view / Fireworks** — camera presets
- **Auto-orbit / Follow a scooter** — camera modes
- **Night / Lantern show / Clear sky / Sound** — scene toggles
- Drag to orbit, scroll to zoom
